# Marlon

# 🏨 HOTEL SYSTEM

Sistema de gestión hotelera desarrollado con Node.js, Express, MySQL y Bootstrap.

---

## 🚀 Características

✅ Login de usuarios
✅ Gestión de habitaciones
✅ Registro de ingresos diarios
✅ Métodos de pago:

* 💵 Efectivo
* 🏦 Transferencia
* 📒 Crédito

✅ Dashboard financiero
✅ Reportes quincenales automáticos
✅ Edición y eliminación de registros
✅ Interfaz moderna y responsive
✅ Formato monetario colombiano ($50.000)

---

## 🛠️ Tecnologías utilizadas

* Node.js
* Express.js
* MySQL
* Bootstrap 5
* HTML5
* CSS3
* JavaScript

---

## 📸 Funcionalidades principales

### 🛏️ Gestión de habitaciones

Permite administrar habitaciones del hotel y registrar ingresos diarios.

### 📊 Reportes quincenales

Genera reportes automáticos por quincena mostrando:

* Valores por habitación
* Totales
* Efectivo recibido
* Transferencias
* Créditos pendientes

### 📈 Dashboard

Visualización rápida de:

* Total efectivo
* Total bancos
* Créditos
* Habitaciones ocupadas

---

## ⚙️ Instalación

Clonar repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Instalar dependencias:

```bash
npm install
```

Ejecutar servidor:

```bash
node server.js
```

---

## 🗄️ Base de datos

Crear una base de datos MySQL llamada:

```sql
hotel_db
```

Importar el archivo SQL correspondiente.
